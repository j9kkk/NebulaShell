### 导入：一张卡三步（设计 §6）

- 步骤条 `选择文件 › 校验预览 › 完成`，`aria-current="step"`；步骤由事件推进，不靠渲染猜。
- 步骤 1：唯一入口是「选择文件」按钮；路径框 `readonly`；虚线区只接拖放（不再是按钮）；格式说明常显；文件级错误用一块错误条（图标 + 后端文案 +「重新选择」，路径框 `aria-invalid`）。
- 步骤 2：摘要 `共 N 台 · 将导入 M 台` + 四个计数 chip；表头全选框（半选 `mixed`）；每行勾选（一致行禁用且不勾）；行内 `#位置`、主机、地址、分组、凭据、处置（冲突行是 `跳过/覆盖` 下拉，其余是类型标签）；折叠用整行按钮「查看全部 N 台 / 收起」；冲突段在卡内（`N 台与本地配置不同` + 跳过/覆盖 + 覆盖时展示会改字段 + 说明）。
- 主按钮按 §9.2 动态：`导入 8 台` / `覆盖 3 台并导入`，0 台时禁用；底栏另有「重新选择」回步骤 1（保留路径与预检结果）。
- 写入中：不确定进度条、X / Esc / 遮罩 / 取消全部禁用（`closeModal` 闸门）。
- 步骤 3：结果报告（五桶统计 + 逐条处置 + 备份路径 +「复制报告」「在文件夹中显示」）；失败态红条写「本次没有写入任何主机」，主按钮变「返回预览」。
- **导入成功不弹 toast**（D8），结果态是唯一报数处。

### 导出：单卡配置态 + 结果态（设计 §7）

- 范围下拉在卡内：`全部 N 台` / `当前筛选 M 台`（仅在确有筛选时出现）/ `已选 K 台`；入口只给默认值。
- 徽标 = 含跳板闭包的实际台数；「附带 N 台跳板机（连同其凭据）」/「不含跳板机」与结果态、toast 共用 `scopeSummary()`，不出现两套数字。
- 格式只读 `JSON 备份`（P0 不做选择器）。
- 「包含凭据」开关（默认开）：关掉后前端传 `withCredentials:false`，后端不写 `credentials` 块并置 `credentialsIncluded:false`；私钥行随之隐藏，说明改为「导入后需重新填写」。
- 「用口令加密」+ `设置文件口令` 口令 + `再次输入`；不足 8 位 / 两次不一致：红框 + 底栏原因 + 禁用。
- 常驻黄色警示块（含凭据但未设口令时）：「内置密钥只能防误读，不能防人」。
- 结果态：`已导出 N 台 · 含 M 台跳板机 · K 个私钥` + 目录/文件名分行的完整路径 + `在文件夹中显示 / 复制路径 / 再导出一份 / 完成`；toast 用同一句摘要并带「在文件夹中显示」。
- 失败：留在卡里、路径保留、按钮恢复，原因进底栏（危险色）。
- 路径规范化（§7.6）：以 `/` 结尾或末段无扩展名 → 视为目录补默认文件名；扩展名不是 `.json` → 纠正；导出文件权限 `0600`。

## 2. 与设计不一致的地方（都已确认原因）

| 设计条目 | 现状 | 原因 |
|---|---|---|
| §6.3 问题区 / 问题行不可勾选（F-09） | 未实现 | 后端逐行校验是**整份拒绝 + 一次列出最多 12 条**（`host_io::format_issues`），没有 `rows[].errors[]`；当前把整段带行号的错误显示在步骤 1 的错误块里。要做设计里的"只导有效行"，需要后端把校验结果结构化（`inspect` 返回 invalid 行）并允许部分写入 |
| §6.3 冲突第三项「新建副本」 | 未实现 | 后端 `decisions` 只认 `skip` / `overwrite`；`copy` 需要新 uuid + 名称后缀 + 跳板 remap，属后端改动 |
| §6.4「下载明细」（`hosts:importReport` CSV） | 未实现 | 需要新增 IPC；当前用「复制报告」（纯文本，含逐条处置与备份路径）替代 |
| §10.2/10.3 文件指纹（`E_FILE_CHANGED`） | 未实现 | 预检与落盘仍各读一次文件；后端契约未落地前前端无法自行校验 |
| §8 表格通道（CSV/XLSX、模板下载） | 未实现 | 设计 §1.1 明确 P1 待裁决，P0 不显示模板入口 |
| §9.4 错误码表（`E_*`） | 文案沿用后端中文 | 后端只发中文串（`err_msg`），没有 `code`；前端不拼错误码，避免出现两套口径 |
| 按钮是否带「…」 | 按钮用 `导入主机` / `导出主机`（不带） | 与 `docs/menu-conventions.md` E1/E5 一致：源码不手写省略号，菜单面由渲染层追加 |

## 3. 本卡顺带的后端改动（2 处，均为 UI 能讲真话的最低前提）

1. `Store::export_hosts_with(scope, pass, with_keys, with_credentials)`：`with_credentials=false` 时不收集凭据、不写 `credentials`；`export_hosts_scoped` 保留为 `true` 的薄包装（既有调用与测试不动）。命令层读 `payload.withCredentials`（缺省开，向后兼容）。
2. `import_run` 规划阶段：`decision == "skip"` 的**新增**主机不再先 push 进 staged；写循环对 `usize::MAX` 占位记一条 `skipped`。此前"取消勾选新增行"仍会建主机 —— 那会让界面说谎。
3. 导出文件写盘统一 `0600`（`write_export_file`）。
