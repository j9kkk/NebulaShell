## 2. 八档定义

```

--fs-xs   11px   次要文本:说明、标签、状态
--fs-sm   12px   正文小号:列表、表单值
```

字号与主题无关，只定义在主 `:root`，亮色块不重复。

**红线断言（这三条是决定本批能不能过的东西）**：
- `.io-item` / `.io-list-head` 的 `height` **没有**出现在样式差异里 → 行高未变（行高由 padding 撑起，不随字号走）。
- `.io-mini-sel` 的 `clientHeight` 未变，只有宽度随内容缩了 2px。
- 6 个场景 `documentElement.scrollWidth - clientWidth = 0`，**页面横向溢出为 0**；宽度变化方向全部是「变小」（`.io-chip` 49→45、`.hl-count` 36→33），不会挤爆列。

另有两处「横向被裁」命中，核查后**与本批无关**：
- `.hl-c-cred`（凭据列，宽 48，scrollWidth 52）：字号 12px **未被本批改动**，且 `overflow:hidden` + `text-overflow:ellipsis`，是「待补全」三个字按设计省略。
- `#settings-sec-terminal`（492 宽，scrollWidth 498）：字号 14px **未改**，是 `overflow-y:auto` 的滚动容器多了滚动条槽位的既有表现。

## 6. 工具改动

1. `lint-css-contract.mjs` 新增 **`token-font`**：`font-size` 只允许 `var(--fs-*)`；`font` 简写里的 px 字号也要标出来（否则会漏掉 14 处）。
2. 替换脚本按值映射一次性替换 396 条声明 + 14 处 `font` 简写，替换后逐项复核唯一值与 lint 命中数。

## 7. 残留与下一批

- `token-color 19` + `media-sizing 7` 仍是 `--strict` 的最后两个拦路虎 → **B4 / B5**。
- 本批没有动 `line-height` 绝对值与字重体系（按卡片边界）；`12px` 仍是绝对主力（132 条），说明「正文 12px」是这个产品的真实基线，换皮阶段若要上调到 13px，应作为独立决策而不是顺手改。
