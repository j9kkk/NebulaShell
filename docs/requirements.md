## 1. 竞品定位总览

| 工具 | 定位 | 对 NebulaShell 的参考价值 |
| --- | --- | --- |
| SecureCRT | 商业企业级标杆 | 会话管理、隧道、脚本、审计 |
| Xshell | 商业(国内企业常用) | 隧道、日志、脚本、Xftp 协同 |
| FinalShell | 免费(国内运维常用) | 免插件服务器监控、SFTP、命令输入框 |
| MobaXterm | Windows 工具箱 | X11/RDP/VNC 多协议、宏、SFTP 弹窗 |
| Tabby | 开源现代终端 | 分屏、主题、插件生态、加密存储 |
| WindTerm | 开源高性能 | ProxyJump、高速传输、锁屏 |
| Termius | 跨端同步 | 主机分组、端到端加密同步、Mosh |
| iTerm2 | macOS 终端 | Triggers、补全、分屏细节 |
| Warp | AI 原生终端 | Blocks、AI 命令生成、Agent 化 |
| PuTTY / Windows Terminal | 基础参照 | 会话模型、profile、串口、日志 |
| Ghostty | 开源 GPU 原生终端(macOS/Linux) | 原生标签/分屏、现代终端协议、命令面板 |
| cmux | 多 Agent 编排终端(macOS) | 多 AI Agent 并行、工作区隔离、内置浏览器 |
| Otty | 原生 GPU 终端(macOS) | 精致原生 UI、AI Agent 深度集成 |
